# 面试刷题助手

一个零依赖、纯前端的面试刷题 Web 应用，帮助你在浏览器里系统地复习面试知识点、自测答题。C++ / Linux / 网络编程 / 数据库模块借助大语言模型（LLM）实时出题，STM32 模块内置 158 题离线题库，**不需要 API Key** 即可练习。

> 项目地址：https://github.com/kkk031210/cpp-quiz
> 在线体验：https://kkk031210.github.io/cpp-quiz/

---

## ✨ 功能特性

- **五大模块**：C++（17 类）· Linux 应用（6 类）· 网络编程（6 类）· 数据库编程（6 类）· STM32 嵌入式（16 章），顶层模块切换器一键切换。
- **两种练习模式**：「自定义组卷」（自选知识点 / 题型 / 数量 / 难度）与「快速练习」（当前模块内随机抽题），均限定在当前模块内。
- **三种题型**：选择题、填空题、简答题。
- **混合判分**：选择题精确匹配；填空题关键词匹配（≥60%）+ 标准答案直接匹配（自动忽略大小写、空格、全半角与标点）；简答题按标准答案要点覆盖率判分，并展示参考答案与要点关键词。
- **离线题库**：STM32 模块题目来自课程笔记整理，全部本地判分，无网络也能刷。
- **学习中心**：按模块筛选的答题统计、正确率与掌握度雷达图、最近 7 天练习趋势（使用 Chart.js）。
- **错题本**：答错自动收录，可按知识点筛选、单独删除或一键清空，并与模块筛选联动。
- **本地持久化**：答题记录、错题本与设置保存在浏览器 `localStorage`，中途退出可继续。

## 🧱 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- [Chart.js](https://www.chartjs.org/)（通过 CDN 引入，用于学习中心图表）
- 浏览器 `localStorage` 做数据持久化
- LLM 调用采用 OpenAI 兼容格式，支持多 Provider

## 🚀 快速开始

本项目为纯静态站点，**无需安装依赖、无需构建**。

方式一：直接打开

```
直接用浏览器打开 index.html 即可。
```

方式二：本地静态服务器（推荐，避免个别浏览器对本地文件协议的限制）

```bash
# Python
python -m http.server 8080

# 或 Node
npx serve .
```

然后访问 `http://localhost:8080`。

## ⚙️ 配置 LLM（可选）

C++ / Linux / 网络 / 数据库模块的 AI 出题与简答评判依赖外部大模型。进入应用内「设置」页：

1. 选择 Provider（DeepSeek / OpenAI / 通义千问 / 智谱清言 / 自定义）。
2. 填入对应的 API Key 与模型。
3. 保存后即可在答题中使用 AI 生成与讲解。

> **STM32 模块无需配置 API Key**，其内置题库完全在浏览器本地抽题与判分。

> API Key 仅保存在你本地浏览器的 `localStorage` 中，不会上传到本仓库或任何第三方服务器（除你所选的 LLM Provider 外）。
